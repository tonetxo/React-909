## Descrición

O Grove Son é unha caixa de ritmos (groovebox) e secuenciador por pasos baseada na web, inspirada na lendaria Roland TR-909. Permite crear patróns de batería, liñas de baixo e experimentar con efectos de vocoder en tempo real, todo dende o teu navegador.

## Características Principais

*   **Secuenciador por Pasos:** Interface intuitiva para programar ritmos e melodías.
*   **Síntese de Son:** Motor de son personalizado construído coa Web Audio API para xerar sons de batería e baixo.
*   **Caixa de Ritmos Estilo 909:** Inclúe sons clásicos como bombo (kick), caixa (snare), hi-hats, toms e claps.
*   **Sintetizador de Baixo:** Un sintetizador monofónico integrado para crear liñas de baixo.
*   **Vocoder en Tempo Real:** Procesa a túa voz ou calquera outra entrada de son a través do micrófono.
*   **Modo Canción:** Encadear patróns para crear cancións completas.
*   **Controis Avanzados:** Axuste de tempo, swing, sinatura de tempo, e parámetros de son por instrumento.
*   **Xestión de Proxectos:** Garda e carga os teus proxectos no almacenamento local do navegador. Exporta e importa proxectos como ficheiros JSON.
*   **Funcionalidades de Edición Rápida:** Copia, pega e limpa patróns de instrumentos para axilizar o fluxo de traballo.

## Tecnoloxías Empregadas

*   **Frontend:** React, TypeScript
*   **Build Tool:** Vite
*   **Audio:** Web Audio API
*   **Estilos:** Tailwind CSS

## Como Executar o Proxecto Localmente

**Requisitos Previos:**
*   [Node.js](https://nodejs.org/) (versión 18 ou superior recomendada)
*   `npm` (normalmente ven con Node.js)

**Pasos:**

1.  **Clonar o Repositorio:**
    ```bash
    git clone <URL-do-repositorio>
    cd <nome-do-directorio>
    ```

2.  **Instalar Dependencias:**
    ```bash
    npm install
    ```

3.  **Executar a Aplicación en Modo Desenvolvemento:**
    ```bash
    npm run dev
    ```
    A aplicación estará dispoñible en `http://localhost:5173` (ou no porto que indique Vite).
